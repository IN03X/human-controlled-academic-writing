# Task Router

Use this file before substantive paper work. Select one primary writing mode when writing or review is requested, then add every gate whose trigger matches the task.

## Primary Writing Mode

1. **Research and plan**
   Use for topic discovery, contribution alignment, novelty stress tests, target-reader definition, or first outlines. Read `early-writing-card.md`.

2. **Outline and contract**
   Use after the broad direction is accepted and before drafting a chapter or a fragile paragraph. Read `outline-contract-card.md`.

3. **Draft and revise**
   Use for manuscript drafting, advisor comments, paragraph repair, related-work revision, transitions, or sentence tightening. Read `draft-revise-card.md`.

4. **Strict review**
   Use for manuscript review, consistency audits, thesis-risk analysis, terminology audits, or final self-checks. Read `strict-review-card.md`.

For synchronization-only, compilation, or paper-file maintenance requests, skip the writing modes and load only the applicable gates.

## Cross-Cutting Gates

Load all that apply:

- Literature, citations, factual claims, or source inspection -> `evidence-gate.md`
- Drafting, reviewing, or polishing manuscript prose -> `prose-style-gates.md`
- Claims about data, code, figures, tables, generated outputs, or experiment completion -> `artifact-consistency-gate.md`
- Short conference, challenge, system, or technical papers, or an explicit request for a compact structure, four-part introduction, or advisor-ready check -> `short-paper-gate.md`
- Overleaf, Dropbox, rclone, pull, push, or a known boundary between local and synchronized paper copies -> `manual-overleaf-sync.md`
- Acoustics-specific examples are needed to resolve an abstract rule -> `acoustics-examples.md`

## Control Mode

- **Alignment:** Use when the request could change an accepted argument or when the user asks to think, compare directions, or avoid editing. Produce a small proposal and wait.
- **Execution:** Use for authorized drafting or low-risk edits inside accepted meaning. Perform the work and verify it with the selected gates.
- **Review:** Diagnose first and remain read-only unless the user also asks for changes.

Do not repeatedly reclassify a continuing task unless its purpose changes. Do not load unrelated cards.
