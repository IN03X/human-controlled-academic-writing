# Folder Corpus Integration

Use this when papers are stored as PDFs in a folder rather than indexed in a QA tool.

## Workflow

1. Build a manifest: title, filename, year, venue, and why it may matter.
2. Search filenames and extracted text for specific terms.
3. Read the most relevant paper sections before citing.
4. Record rejected or low-relevance sources.

## Rule

Folder search can find candidate papers, but manuscript claims still need paper-level inspection.
